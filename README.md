# Learna Inglés
App Android para aprender inglés: lecciones por niveles (A1, A2, B1), pronunciación con micrófono y chat con tutor IA.

1. Sube esta carpeta a un repositorio de GitHub (rama `main`).
2. GitHub Actions compila solo; el APK aparece en **Releases**.
3. Instala el APK en el teléfono. En Ajustes pega tu clave de API de Anthropic para activar el chat.
